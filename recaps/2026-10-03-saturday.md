### This week's nudge

Three specific experiments worth running in the next 1–2 hours each. These are different angles on the same territory as last time — try whichever entry point feels lowest-friction right now.

**1. Just run the analysis (5-parameter ethics pass)**
Open `ethics and trust/wireframes.html` in a browser. Pick one screen. Write a single Claude prompt that asks it to assess that screen against Trust, Explainability, Transparency, Fairness, and Accountability — with the constraint that each finding must be tagged as either "designer controls this," "needs cross-functional buy-in," or "outside design scope." Don't aim for a polished output. The question is whether the raw response is coherent and useful at all. One hour, one artifact, one verdict. This closes the longest-open loop in the whole repo.

**2. Claude Code hook that auto-reviews a design artifact on save**
Write a Claude Code hook (post-tool-use) that, when a `.html` or `.png` file changes inside `ethics and trust/`, automatically runs a short ethics pass and appends the output to a `REVIEW.md` in that folder. The goal isn't a rigorous tool — it's to test whether a routine can bring AI ethics review into a design workflow the same way linting brings code quality into a dev workflow. This is a direct test of an AI-native design practice concept: code-style automation applied to design decisions. Doable in under two hours.

**3. Write the experiment brief before you build anything else**
The ethics analyzer has high artifact potential but the hypothesis is still fuzzy. Spend one hour writing a 300-word document that answers: What question is this experiment actually trying to answer? What would a "useful" output look like vs. a "useless" one? Who is the reader — a UX designer, a design manager, a product team? Articulating the hypothesis before running the experiment (even retrospectively) will make both the run and the eventual writeup faster and sharper. File it as `ethics and trust/brief.md`. This is the lowest-effort unlock for everything downstream.
