### This week's nudge

Two quiet weeks in a row is data, not coincidence. The nudges this week are more direct.

**1. Run the ethics audit — no tool, no UI, just the output**
Open `ethics and trust/wireframes.html` in a browser. Write a 5-sentence Claude prompt asking it to assess the wireframe against Trust, Explainability, Transparency, Fairness, and Accountability. Paste the HTML or describe the UI decisions in plain text. Read the output. Write one paragraph in the experiment's READ.md: was the output useful to a designer, or did it read like a compliance checklist? That paragraph is the experiment result. Two weeks of nudges point here. Forty-five minutes closes the loop.

**2. Build a designer accountability matrix (single HTML page)**
The ethics experiment raised a question it never answered: what do UX designers actually own vs. what requires cross-functional buy-in? Build one self-contained HTML page — no framework, no backend — that takes a feature description as input and outputs a 3-column matrix (designer owns / cross-functional / outside scope) with the five ethics parameters as rows. The goal isn't a polished tool; it's to find out whether that structure is actually useful to a designer or just creates more bureaucracy. The discovery is the experiment.

**3. Write a Claude prompt that scaffolds new experiments**
The hardest part of starting an experiment is the blank page. Write a Claude prompt (or Claude Code slash command) that takes a hypothesis in plain English and generates: a filled-in READ.md, a one-line statement of what to build first, and a suggested first commit message. Save it in the `template/` folder in `dinudey/experiments`. This directly lowers the friction between having an idea and starting one — which is the real thing slowing the experiment queue down.
