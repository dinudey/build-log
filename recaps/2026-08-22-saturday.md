## This week's nudge

No activity across experiments this week. Three concrete experiments worth trying — each doable in 1–2 hours:

**1. Audit your own ethics wireframes with Claude**
You built an AI UX Ethics Analyzer to evaluate other people's work — now run it on itself. Open `ethics and trust/wireframes.html` and paste it into a Claude conversation with a prompt asking it to assess the wireframes against the same five parameters the tool is designed to use (Trust, Explainability, Transparency, Fairness, Accountability). The meta question is whether the tool surfaces blind spots in its own design. Document what Claude calls out versus what you'd defend. That tension is the experiment, and it's a one-session result worth capturing.

**2. Build a Claude Code routine that writes your daily standup**
Set up a scheduled Claude Code session that reads the git log from the past 24 hours across your repos, then writes a 3-sentence standup to a `standups/YYYY-MM-DD.md` file. The interesting design question isn't the automation — it's what gets lost when commit messages become the source of truth for "what you did." Run it for three days and compare the generated output to how you'd actually describe the work. That gap is a finding about AI-native documentation practice.

**3. Prototype a "design decision log" that lives next to the code**
Pick one small UI component you've built or wireframed. Write a `DECISIONS.md` next to it that captures the *why* behind each visual choice — not what it looks like, but what it's optimizing for. Then ask Claude to read the component code (or HTML) alongside the decision log and identify where the implementation diverges from the stated intent. This is an AI-native design practice experiment: treating design rationale as machine-readable artifact, and using Claude as a divergence detector between intent and execution.
