### This week's nudge

Three experiments worth running in the next 1–2 hours each. All are distinct from the September nudges; all are buildable without setup.

**1. Run the ethics audit — take 2, with a meta-loop**
The wireframes in `ethics and trust/wireframes.html` were designed as the *output* of an ethics analysis. Use them as the *input*. Screenshot the file, write a prompt using the five parameters from READ.md, and run it through Claude. The meta-question — does the ethics UI itself earn user trust, or does it read like a compliance dashboard? — is more interesting than any neutral test case. Target output: one real assessment in hand, plus a written verdict on whether the language is useful to a designer or feels like researcher-speak. The finding either way closes the open loop.

**2. Build a minimal AI decision-log component**
Design and build a single-file HTML/JS component that surfaces AI model decisions in a user-facing UI: which model was invoked, when, what the user submitted (abbreviated), and whether a human reviewed the output. No backend — localStorage only. The design question it answers: what's the minimum disclosure surface that feels honest rather than paranoid? Narrow scope, real UI to evaluate at the end, and it feeds directly into the ethics experiment as reference material. Aim for something you'd actually want in a product, not a mockup.

**3. Write a scheduled design-critique routine for this repo**
Write a Claude Code scheduled routine that runs once a week, reads `experiments/ethics and trust/wireframes.html`, and writes a three-paragraph critique to a `critique/` folder in experiments. Three fixed paragraphs: what communicates its purpose without explanation, where the UI needs user trust it hasn't earned yet, and what a user scanning for three seconds would misunderstand. Two reasons to do this: it creates standing accountability for finishing the experiment, and it tests whether automated design critique on a cadence produces anything actually useful — which is itself worth knowing.
