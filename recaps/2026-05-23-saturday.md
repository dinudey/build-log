## This week's nudge

No activity this week — three concrete experiments worth trying, each doable in 1–2 hours:

**1. Run the ethics audit for real**
The `ethics and trust/wireframes.html` exists but has never been evaluated. Open it in Claude Code, feed it to Claude with a structured prompt asking for a breakdown across Trust, Explainability, Transparency, Fairness, and Accountability — and for each finding, tag it as *designer-owned*, *cross-functional*, or *out of scope*. The experiment's core question (can Claude make ethics actionable for a UX designer, not just descriptive?) won't answer itself. Log what you'd need to change about the prompt to make the output actually useful in a real design review.

**2. Build a commit interpreter hook**
Set up a Claude Code post-commit hook that reads the diff and writes a one-paragraph contextual note — not a file-change summary, but an interpretation of what decision was made and why it matters. Test it on 3–4 commits from the `experiments` repo history. The real question: can Claude infer intent from markup and code changes alone, or does it need scaffolding to be useful? The answer shapes how much you'd trust auto-generated changelogs.

**3. Consent flow in two modes**
Design a data-use transparency / consent flow twice: once freehand, once by giving Claude a constraint list (surface what data is used before asking for consent, no dark patterns, legible to someone who doesn't know what "analytics" means) and asking for three variants. Don't compare the outputs — compare what each process forced you to think about. That delta is the finding worth documenting.
