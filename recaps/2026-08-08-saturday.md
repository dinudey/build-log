Feed `ethics and trust/wireframes.html` back to Claude and ask it to score the dashboard against the five parameters it was designed to evaluate (Trust, Explainability, Transparency, Fairness, Accountability). This is a recursive test with real signal: does the tool embody the rubric it applies to others? Document the gaps. This closes the loop on the existing experiment and likely surfaces the most interesting finding the project has produced so far.

**2. Build a design decision log hook in Claude Code**
Add a `Stop` hook to Claude Code that, after any session touching an HTML prototype in the experiments repo, generates a 3–5 line design decision entry and appends it to a `DECISIONS.md` in the experiment folder. The hook prompt should capture: what was changed, what was considered but rejected, and what constraint drove the final choice. This tests whether AI-native design practice can maintain a rationale trail with zero manual effort — and produces raw material for artifact writing later.

**3. Prototype an AI transparency receipt**
Build a single-page HTML artifact (target: under 150 lines, no external dependencies, no framework) that renders one AI-generated design recommendation as a structured receipt: what was asked, what was weighed, what was decided, what was left out. Use the visual language of a transaction receipt — monospace, line items, totals — to make AI reasoning legible to a non-technical stakeholder without explanatory prose. This is a 90-minute build with direct artifact potential.
