### This week's nudge

Three experiments worth trying in the next 1–2 hours each — different from last month's suggestions, in case those didn't stick:

**1. Prompt archaeology: document one Claude Code conversation that produced something real**
Take any prior session where Claude Code helped you do something non-trivial — a design decision, a build, an analysis — and reconstruct the prompting pattern that made it work. What was the setup prompt? What constraint or framing unlocked good output? What didn't work first? Write it up as a `patterns/` file in this repo: a named pattern, the prompt template, and two sentences on when to reach for it. This is the most underrated artifact type in AI-native practice — reusable prompting patterns — and it takes nothing to build.

**2. A streaming-text component for AI interfaces**
Build a single self-contained HTML file with a streaming text display — the kind of progressive character-by-character or token-by-token reveal that has become the signature of AI interfaces. Add three variants: word-level reveal with a blinking cursor, a "thinking" ellipsis followed by full reveal, and a sentence-chunked reveal. No framework, no build step, ~60 lines. The goal is to understand the UX mechanics well enough to have a point of view on when each feels right vs. when the animation is noise. Ships as a reference component.

**3. A Claude Code hook that writes your end-of-session note**
Write a `SessionStop` hook that, when a Claude Code cloud session ends, appends a one-line summary to `wip/current.md` in this repo: the date, what Claude touched (extracted from git status or the session directory), and a prompt for the next session to continue. This is a 30-minute build that solves the actual friction in iterative AI-assisted work: losing context between sessions. The routine itself becomes a pattern worth writing about.
