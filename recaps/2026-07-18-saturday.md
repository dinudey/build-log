## This week's nudge

Three concrete experiments, each doable in 1–2 hours:

**1. Ethics Analyzer: from wireframe to working tool**
The `ethics and trust` experiment produced wireframe concepts but no working prototype. The next step is a single HTML file: paste a product flow or design brief, and Claude returns a structured critique across Trust, Explainability, Transparency, Fairness, and Accountability — each flagged as "designer can fix," "needs collaboration," or "out of scope." The real test isn't whether Claude can find issues; it's whether the output is specific enough that a UX designer can act on it in Figma without calling an engineer first. ~2 hours.

**2. Claude Code commit narrator**
Set up a Claude Code post-commit hook that appends a one-sentence "what changed and why" to a local `decisions.md` after every commit — synthesizing intent, not just diffing files. The interesting design constraint: it should read like a human wrote it, not a changelog. Tests whether AI can narrate reasoning in a way that makes codebases easier to hand off or resume after a break. ~1 hour to wire up, another 30 min to tune the prompt until the output is actually useful.

**3. AI-adaptive onboarding prototype**
Build a minimal HTML prototype of a product onboarding flow where Claude shapes the path in real time based on what the user reveals in early steps — skipping irrelevant sections, reframing later questions, surfacing examples that fit their context. Scope it tightly: one persona type, three decision points. The question is whether an adaptive flow feels *helpful* or *uncanny*. That answer is worth knowing before designing a full system around it. ~2 hours.
