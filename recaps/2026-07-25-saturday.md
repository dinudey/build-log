## This week's nudge

No commits landed this week. Three concrete experiments worth trying in 1–2 hours each:

**1. Run the ethics analyzer — actually close the loop on the existing experiment**
The `ethics and trust/wireframes.html` file already exists. Open it in a browser, describe or screenshot 2–3 screens to Claude, and ask it to assess them against the five parameters — with each finding tagged as "designer-controllable," "cross-functional," or "out of scope." Document the output as a findings.md in the same folder. This is the original question the experiment was set up to answer, and it's 30 minutes away.

**2. Claude Code routine for self-documenting experiments**
Write a Claude Code scheduled prompt (or PostToolUse hook) that runs whenever a new `.html` file appears in `experiments/` and automatically generates a brief accessibility + ethics surface scan saved as a sidecar `.scan.md` file. This turns every future experiment into a self-documenting artifact from day one — and the hook setup itself is a concrete example of AI-native development practice worth writing up.

**3. Single-page ethics impact card generator**
Build a standalone HTML + JS page (no backend needed) where you paste a feature description or design decision, and it returns a structured impact card: which of the five ethics parameters are at risk, the likely tradeoffs, and a responsibility mapping (designer / PM / eng / legal / out of scope). Uses the same conceptual framework as the existing experiment but as a reusable tool rather than a one-time analysis. Doable in 90 minutes with Claude Code, and a natural candidate for a shareable artifact.
