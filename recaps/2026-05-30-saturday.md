## This week's nudge

No activity this week. Three specific things worth picking up — each scoped to 1–2 hours.

**1. Close the ethics wireframes loop**
The experiment set out to test whether Claude can audit UI artifacts against five ethics parameters and make the output actionable for designers. The wireframes got built, but Claude never actually performed the audit. Feed `ethics and trust/wireframes.html` to Claude with this specific prompt structure: *"Audit this prototype against Trust, Explainability, Transparency, Fairness, and Accountability. For each parameter, list what a UX designer can address directly, what requires cross-functional collaboration, and what is outside design's scope."* Write the output into a `findings.md` in the same folder. The interesting signal is whether Claude's categorization of design-vs-cross-functional matches your intuition, or surprises you.

**2. Resurrect the ADHD tool as one interaction**
The adhd-learning-tool directory was created and deleted on April 18 without becoming anything real. Pick the single hardest moment in a learning tool for ADHD users — the moment when attention breaks and the tool either helps or loses the person — and build just that moment as a single HTML file using Claude Code. No full app, no navigation. The experiment question: how much does Claude default to cognitive accessibility scaffolding (chunking, progress visibility, low-distraction layout) without being asked, versus what requires explicit prompting? Document the delta between Claude's first output and what you had to correct.

**3. Build a trust-disclosure micro-pattern, twice**
Pick one moment in any AI product where a decision gets surfaced to a user — a recommendation, a content summary, a categorization. Use Claude Code to build that moment two ways: once with no explanation UI (just the output), once with a lightweight trust/reasoning disclosure (confidence signal, brief rationale, an override affordance). The goal is not to compare the two designs — it's to observe what Claude defaults to when designing for opacity vs. transparency, and whether it needs to be pushed to produce accessible, non-patronizing language in the disclosure version. Deliverable: two self-contained HTML snippets in a new `ai-disclosure-pattern/` folder.
