**What I worked on**

### AI UX Ethics Analyzer (`ethics and trust/`)

The question being explored: can Claude analyze visual artifacts — wireframes, prototypes, HTML mockups — against a structured ethics rubric (Trust, Explainability, Transparency, Fairness, Accountability) in a way that's genuinely useful to a UX designer, not just a researcher or compliance officer? The secondary question is whether the output can distinguish between what the designer can fix directly, what needs cross-functional coordination, and what's entirely outside design's scope.

What was actually built was a set of dashboard wireframe explorations using Claude Code Design — the `wireframes.html` file clocks in at 71KB, indicating multiple interface concepts for how an ethics analysis report might be surfaced to a designer as a working tool. The session went from idea to explored UI in a single sitting.

An earlier experiment (an ADHD learning tool) was started and deleted in the same session — it didn't survive structuring, which itself is useful signal about the quality of the hypothesis.

---

**Key decisions or tradeoffs**

- **Designer agency as the organizing principle**: Sorting ethics findings by who can act on them (designer alone vs. requires escalation vs. out of scope) is the design decision that separates this from generic AI ethics checklists. It makes the tool feel like a collaborator rather than an audit report.
- **Prototyping-first strategy**: The UI was explored before any analysis engine was built. This is the right call for validating that the output *format* is useful before investing in the *quality* of what fills it.
- **Claude Code Design as the medium**: Using an AI-native design tool to prototype an AI-native design tool is a deliberate recursion — the process is part of the point.

---

**What it unlocked**

- A concrete interface model for AI-assisted ethics review situated in UX practice rather than compliance frameworks.
- Early evidence that Claude Code Design can turn a structured brief into explorable wireframes fast enough to be a genuine thinking partner, not just a rendering tool.

The wireframes exist; now find out if the analysis works. Pick 3 real AI product screens — a chatbot onboarding, a content moderation interface, a recommendation UI.
