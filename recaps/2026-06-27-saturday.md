## This week's nudge

No activity this week. Three experiments worth trying — each scoped to 1–2 hours.

**1. Close the ethics analyzer loop**
The wireframes are built and sitting in the repo. The gap is the evaluation prompt. Write a structured prompt that feeds the wireframes.html to Claude and asks it to score each screen against the five parameters — Trust, Explainability, Transparency, Fairness, Accountability — with output formatted for a UX designer, not an ethicist or compliance officer. The interesting design question to probe: does Claude distinguish between what a designer can fix directly in Figma vs. what requires an engineering or policy conversation? Run it, capture the output, and mark the experiment done or iterated. This closes a 10-week-old open loop.

**2. Session-end hook that writes a daily one-liner**
Set up a Claude Code hook that appends a single sentence to `log/daily.md` in build-log at the end of each working session: one thing worked on, one thing left open. Run it for three sessions. This exercises Claude Code's hook system in a low-stakes context and generates the raw material that makes weekly recaps easier to write — instead of reconstructing intent from commit messages, you're pulling from live session notes written in the moment.

**3. Decision surface audit on one AI product screen**
Pick any screen from a product that uses AI — a recommendation feed, a moderation queue, a search results page. Use Claude to enumerate every point where an algorithmic decision affects what the user sees or can do. Categorize each as: visible (user knows AI decided this), implied (there are signals but no disclosure), or invisible (user has no idea this was a decision). Output: a one-page constraint map. This turns the ethics experiment from a conceptual framework into a repeatable audit method, and it's the kind of thing that's publishable on its own.
